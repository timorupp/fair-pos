ADMINSTUFEN-MATRIX (Task #94)
==============================================================================

Vollstaendige Liste aller /api/admin/*-Routen (Stand 2026-08-30, aus dem
Code extrahiert - jede Zeile entspricht einem tatsaechlichen
Fastify-Route-Handler, keine Vermutung). Zweck: Grundlage, um jeder Route
eine Adminstufe zuzuordnen, bevor Task #94 umgesetzt wird.

Pro Route drei Zeilen:
  ROUTE        - Methode + Pfad
  Beschreibung - was die Route tut
  Vorschlag    - meine Einschaetzung als Ausgangspunkt (siehe Legende)
  Entscheidung - hier deine endgueltige Zuordnung eintragen. Leer lassen
                 heisst "Vorschlag uebernehmen".

Legende: S = System-Administrator
         V = Veranstaltungs-Administrator
         S+V = beide ausdruecklich
         ?   = noch ungeklaert, brauche deine Einschaetzung
